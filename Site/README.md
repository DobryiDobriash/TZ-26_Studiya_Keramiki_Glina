# GLINA — YouTube / Telegram UTM patch

## Что входит
- `js/analytics.js` — сохранение UTM-атрибуции в пределах сессии, передача UTM в скрытые поля форм и отслеживание кликов по элементам с `data-cta`.
- `docs/social-buttons.html` — пример блока кнопок YouTube и Telegram и ссылки с UTM.
- `docs/utm.csv` — таблица примеров UTM.

## Как подключить
1. Скопируйте `js/analytics.js` в существующую папку `js/` сайта (сначала сравните с текущим `js/analytics.js`, не перезаписывайте другие события GA4 без объединения).
2. Подключите скрипт на всех страницах сайта после инициализации `gtag.js`, например перед `</body>`:
   `<script src="/js/analytics.js" defer></script>`
3. Добавьте обе социальные кнопки в общий header/footer сайта и в блоки CTA на страницах, где посетителя зовут перейти в соцсети. Замените `YOUR_CHANNEL` на настоящие адреса.
4. Для ссылок, ведущих С YouTube/Telegram НА сайт, используйте примеры из `docs/utm.csv`. UTM добавляют к ссылкам на целевую страницу, размещённым на внешней площадке, а не к ссылкам с сайта на соцсеть.
5. Проверьте отправку тестовой заявки: `utm_source`, `utm_medium`, `utm_campaign` должны попасть в backend/CRM. Убедитесь, что backend сохраняет эти поля. Если API принимает только фиксированный список полей, обновите его отдельно.
6. Проверьте GA4 DebugView: клики по кнопкам с `data-cta` должны отправлять событие `cta_click`. Не отправляйте в GA4 имя, email или телефон.

## Где разместить кнопки
- общий header/footer — если каналы должны быть доступны с любой страницы;
- `index.html`, `classes.html`, `schedule.html`, `gallery.html`, `gift.html`, `corporate.html`, `contacts.html` — в видимых CTA-блоках там, где это соответствует сценарию страницы;
- страница благодарности — только если есть смысл продолжить взаимодействие, без повторного отправления формы;
- не добавляйте одинаковые кнопки в каждом блоке автоматически: избегайте дублирования и проверяйте мобильную версию.

## Важно
Это патч-шаблон, а не автоматически слитая версия исходного проекта: архив GLINA в этой среде не удалось безопасно распаковать/проверить и перезаписать существующие файлы. Перед публикацией объедините обработчик с текущими `js/analytics.js` и `js/form.js`, проверьте реальные селекторы форм, домен и адреса каналов.
