# Как устроен сайт «Глина» — объяснение кода

## 1. `index.html` и остальные HTML-файлы — содержание
Каждый HTML-файл отвечает за отдельную страницу. Внутри него:
- `<head>`: кодировка, мобильный viewport, описание для поисковиков, Open Graph-превью, шрифт и подключения CSS/JS.
- `<header>`: общая шапка, логотип, меню и телефон.
- `<main>`: уникальное содержимое страницы — карточки, расписание, сертификат, форма и т. д.
- `<footer>`: единый подвал с контактами, навигацией и соцсетями.
- `data-event` и `data-*`: атрибуты, с помощью которых `analytics.js` понимает, какое событие отправить при клике.

## 2. `css/style.css` — внешний вид
- `:root`: фирменные цвета в CSS-переменных. Например, `--terracotta` — терракотовый акцент, `--cream` — фон, `--graphite` — основной текст.
- Общие правила (`body`, заголовки, ссылки, кнопки): единая типографика, цвета, отступы и состояния фокуса.
- `.site-header`, `.main-nav`, `.site-footer`: шапка, навигация и подвал.
- `.hero`, `.hero-art`, `.hero-pot`: первый экран главной и декоративная ваза, нарисованная CSS.
- `.cards`, `.three`, `.format-card`: сетка и карточки форматов.
- `.calculator`, `.calc-box`, `.calc-result`: оформление калькулятора.
- `.schedule-layout`, `.schedule-day`, `.slot`: расписание и кнопки временных слотов.
- `.gift-layout`, `.certificate`, `.cert-vase`: форма и макет подарочного сертификата.
- `.gallery-grid`, `.gallery-piece`, `.lightbox`: сетка галереи и увеличенный просмотр.
- `.lead-form`, `.invalid`, `.field-error`: поля заявки и визуальное отображение ошибок.
- `@media(max-width:800px)` и `@media(max-width:520px)`: адаптивные стили для планшетов и телефонов; меню становится раскрывающимся, сетки переходят в одну или две колонки.

## 3. `js/main.js` — интерактивность
Код запускается после события `DOMContentLoaded`, когда HTML уже разобран браузером.
- **Меню:** кнопка ☰ переключает класс `open`, а CSS показывает/скрывает мобильную навигацию.
- **Калькулятор:** объект `prices` содержит базовые цены. Функция `updateCalculator()` читает выбранный формат и число гостей, вычисляет сумму и выводит её в элемент `#total-price`. Для корпоратива минимум 6 гостей; для «Свидания» цена считается за пару.
- **Расписание:** массив `slots` строится на 14 дней. Для будней задаются 12:00, 15:00, 19:00, для выходных — 11:00, 14:00, 17:00. Поле `seats` демонстрационно рассчитывается формулой; в реальном проекте его нужно брать из базы/таблицы. Если мест 0, кнопка отключена. Перед переходом к форме число гостей сравнивается с числом свободных мест.
- **Сертификат:** `updateGift()` обновляет имя, формат и пожелание в макете при каждом изменении поля. `maxlength` в HTML ограничивает имя 30 символами, пожелание — 80.
- **Промокод:** кнопка копирует `CLAY10` через Clipboard API; если браузер запрещает копирование, выводится запасной текст.
- **Галерея:** нажатие на карточку показывает overlay (lightbox), крестик или нажатие на фон закрывает его.
- **Форма:** UTM-метки читаются из адреса и сохраняются в `sessionStorage`; выбранный слот также переносится на страницу контактов. Проверяются имя, телефон, e-mail и обязательное согласие. В демонстрационном режиме заявка записывается в `localStorage`, ей создаётся `REQ-...`, после чего открывается `thanks.html`.
- **Страница спасибо:** читает номер заявки из `sessionStorage` и показывает его пользователю.

## 4. `js/analytics.js` — аналитические события
- `GA_ID` — место для настоящего ID потока Google Analytics 4. Заглушка `G-XXXXXXXXXX` специально не отправляет данные в GA4.
- `send(name, params)` сохраняет последние демонстрационные события в `sessionStorage` и, только если задан реальный ID и загружен `gtag`, вызывает `gtag('event', ...)`.
- Обработчик кликов считывает `data-event` и соответствующие атрибуты `data-button-name`, `data-contact-type` и т. д.
- Пользовательские события из `main.js` (`glina:class-calc`, `glina:slot-select`, `glina:lead-success`) преобразуются в события аналитики.
- В production событие `generate_lead` нужно отправлять только после ответа сервера `ok: true`. В этой учебной версии оно означает успешную локальную проверку формы и НЕ доказывает, что заявка доставлена администратору.

## 5. `js/form.js` — место подключения сервера
Сейчас здесь оставлена константа `GLINA_FORM_ENDPOINT`. После публикации Google Apps Script Web App в неё добавляется адрес приёмника. Сам файл — заготовка, а не работающий серверный отправитель. Чтобы заявки поступали в Google Таблицу, требуется написать и развернуть серверный `doPost(e)`, подключить `fetch`, проверять поля повторно на сервере и обрабатывать ответ.

## 6. `files/corporate-presentation.pdf`
Небольшая PDF-презентация корпоративного формата: условия, цена, что входит, контакты.

## 7. `docs/utm.csv`
Шаблон реестра UTM-ссылок для Instagram, ВКонтакте, Telegram, YouTube, партнёров и QR-кода. Перед публикацией нужно заменить `<ваш-домен>` реальным адресом сайта, проверить метки и внести фактические короткие ссылки.

## 8. `docs/events.md`, `docs/prompts.md`, `docs/report.md`, `docs/images.md`
- `events.md`: события и параметры.
- `prompts.md`: журнал использованных запросов и этапов работы.
- `report.md`: шаблон аналитической записки, куда вписываются только реальные цифры из GA4.
- `images.md`: пояснение, что декоративная галерея пока не использует фотографии реальных изделий.

## 9. Как запустить
1. Распакуйте ZIP.
2. Откройте `index.html` двойным щелчком в браузере. Для локального сервера откройте терминал в папке и запустите `python -m http.server 8000`, затем перейдите на `http://localhost:8000`.
3. Для публикации загрузите папку в GitHub и подключите репозиторий в Vercel.

## 10. Что пока демонстрационное
- Заявки сохраняются только в браузере пользователя, а не в Google Таблице.
- Расписание и свободные места сгенерированы на стороне JavaScript и не блокируются для нескольких посетителей одновременно.
- GA4 ID — заглушка; реальная аналитика не подключена.
- Галерея состоит из CSS-макетов, а не реальных фотографий гостей.
- Автоответы Instagram / ManyChat, таблица, Apps Script и DataLens нужно подключить отдельно.
- Текст политики конфиденциальности — учебный шаблон для проверки специалистом.
