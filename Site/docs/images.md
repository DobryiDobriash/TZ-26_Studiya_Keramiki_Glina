# Изображения

Иллюстрации в текущей версии созданы средствами CSS и SVG, поэтому внешние фотоматериалы не используются. Макеты галереи — декоративные векторные изображения, а не реальные изделия гостей. Перед коммерческой публикацией замените их на фотографии с разрешением владельцев и укажите источник/лицензию.
